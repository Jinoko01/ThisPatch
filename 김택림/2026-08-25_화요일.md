# TIL - 2026-08-25 (화)

## 오늘 한 것

빅데이터 분산 프로젝트 주제를 구체화하면서 Steam 데이터를 활용한 서비스 가능성을 검토했다.

단순히 리뷰를 분석하는 수준보다, Steam에 흩어져 있는 여러 데이터를 연결해 게임 개발자가 참고할 수 있는 형태가 더 적절하다고 판단했다.

검토한 주요 데이터는 다음과 같다.

- Steam 게임 메타데이터
- 게임 태그
- 사용자 리뷰
- 리뷰 작성 시점 플레이타임
- 패치 노트 / 뉴스
- CCU
- DLC, 언어, 도전과제 등 확장 데이터

또한 프로젝트가 단순 데이터 조회 서비스가 되지 않도록, 분산처리가 자연스럽게 필요한 작업을 고민했다.

- 대규모 Historical Backfill
- 리뷰/패치 텍스트 NLP
- 게임별·패치별 시계열 집계
- 패치 전후 Window Join
- 유사 패치 검색

## 배운 것

빅데이터 프로젝트에서는 데이터의 크기만 큰 것보다, 실제 서비스 기능이 대규모 연산과 자연스럽게 연결되는지가 중요하다.

특히 Steam처럼 데이터 종류가 여러 개인 경우 각각을 따로 보여주는 것보다 `게임 → 이벤트 → 사용자 반응`처럼 관계를 정의하는 것이 서비스의 차별점이 될 수 있다.

## 느낀 점

처음에는 기능 아이디어를 많이 붙이는 방향으로 생각했지만, 핵심 질문을 먼저 정해야 전체 구조가 깔끔해진다는 것을 느꼈다.

이 과정에서 다음과 같은 질문을 중심으로 아이디어를 검토했다.

> 비슷한 게임들은 실제로 어떻게 운영되고 있으며, 특정 변경 이후 사용자들은 어떤 반응을 보였는가?
