## 2. JavaScript 변수 선언과 스코프 체계

- **`var` vs `let` / `const`의 차이**:
  - `var`: 함수 레벨 스코프, 변수 재선언 및 재할당 가능, 호이스팅 시 `undefined`로 초기화되어 버그 유발 가능성 큼
  - `let` / `const`: 블록 레벨 스코프(`{}`), 변수 재선언 불가 (`const`는 재할당 불가)
- **TDZ (Temporal Dead Zone, 일시적 사각지대)**:
  - `let`과 `const`는 선언 단계와 초기화 단계가 분리되어 호이스팅 시 초기화 전에 접근하면 `ReferenceError`가 발생하여 안전한 코드 작성 지원
- **불변성과 참조형 데이터**:
  - `const`로 선언된 객체/배열은 참조 주소는 고정되지만 내부 프로퍼티 변경은 가능하므로, 데이터 불변성 유지의 개념을 이해했다.

## 3. JavaScript 함수와 문법 표현식

- **함수 선언문과 함수 표현식**:
  - 함수 선언문(호이스팅 발생)과 함수 표현식(변수 할당 방식)의 차이점 정리
- **화살표 함수 (Arrow Function)**:
  - `function` 키워드 대신 `() => {}` 형태로 간결하게 함수를 선언하는 문법 학습
  - 내부 `this` 바인딩이 상위 스코프를 따르는 Lexical this 특성 파악
- **템플릿 리터럴 및 논리 단축 평가**:
  - 백틱(`` ` ``)과 `${}`를 활용한 간결한 문자열 조합 방식
  - `&&` 및 `||`를 활용하여 기본값 지정과 조건부 실행을 간결하게 처리하는 패턴 학습

## 4. 구조 분해 할당과 배열 고차 함수

- **구조 분해 할당 (Destructuring Assignment)**:
  - 객체나 배열의 속성을 분해하여 개별 변수에 직관적으로 할당하는 문법 복습
- **스프레드 / 레스트 연산자 (`...`)**:
  - 배열과 객체를 원본 훼손 없이 복사(얕은 복사)하고 요소를 병합하거나 가변 인자를 다루는 방식 확인
- **배열 고차 함수 기초 (`map`, `filter`, `reduce`)**:
  - `map()`: 배열 내 각 요소를 변환하여 새로운 배열을 반환 (데이터 가공의 기본)
  - `filter()`: 조건을 만족하는 요소만 걸러내어 새 배열 생성
  - `reduce()`: 배열 요소를 순회하며 누적 값을 계산하는 패턴 연습
