# TIL 2026-08-27 (목)

## TypeScript 기본 개념

- JS에 타입을 붙여 컴파일 단계에서 오류를 미리 잡는 언어라는 점을 배웠다.
- `string`, `number`, `boolean`, 배열, 객체 타입 선언 방법을 정리했다.
- 함수 매개변수와 반환값에 타입을 지정하는 방식을 살펴봤다.

## React 기본 개념

- UI를 컴포넌트 단위로 나누어 재사용하는 라이브러리라는 점을 배웠다.
- 선언적으로 화면을 작성하고, 상태가 바뀌면 UI가 다시 그려진다는 흐름을 이해했다.

## JSX 렌더링 동작 원리

- JSX는 HTML처럼 보이지만 JS 문법이며, 결국 `React.createElement` 호출로 변환된다.
- 변환된 요소가 Virtual DOM에 반영되고, 실제 DOM과 비교해 필요한 부분만 업데이트된다.
- JSX 안에서 JS 표현식은 `{}`로 넣고, 컴포넌트는 대문자로 시작해야 한다.

## 컴포넌트 구조와 props/state

- 컴포넌트는 부모 → 자식으로 `props`를 내려 데이터를 전달한다.
- `state`는 컴포넌트가 스스로 가지는 값이고, 바뀌면 해당 컴포넌트가 다시 렌더링된다.
- props는 읽기 전용이고, 값을 바꿔야 하면 부모가 state를 들고 콜백으로 내려주는 패턴을 배웠다.
