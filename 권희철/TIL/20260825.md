# TIL 2026-08-25 (화)

## DevPulse 아이디어 기획

- 전 세계 GitHub 공개 활동으로 **지금 무슨 일이 일어나는지**(트렌드·급상승 레포)와 **나는 어디에 있는지**(개인 커리어 리포트)를 보여주는 서비스를 기획했다.
- 주 타깃은 주니어·취준생(커리어 리포트), 부 타깃은 현직 개발자(분야별 브리핑·급상승 레이더)로 잡았다.
- 모든 기능은 프론트엔드/백엔드/AI/인프라 등 **분야 필터**를 기본으로 두기로 했다.

## 핵심 기능

- 데일리 데브 브리핑: 카테고리별로 생태계 움직임을 매일 정리한다.
- 급상승 레포 레이더 + AI 해설: 평소 대비 급등 레포를 감지하고, README·릴리스노트·Hacker News 반응으로 “왜 뜨는지”를 해설한다.
- 개인 커리어 리포트: GitHub 계정을 넣으면 동일 분야 내 백분위와 학습 방향을 제시한다.

## 데이터와 분산 처리

- GH Archive(과거 배치) + GitHub Events API(실시간) + REST API(메타·개인 조회)를 쓰는 흐름을 정리했다.
- 무거운 집계는 노트북 6대 클러스터가 미리 하고, 개인 조회는 서비스 서버가 즉석 처리한다.
- GH Archive는 TB 규모라 단일 머신으로는 어렵고, 배치 + 스트리밍 람다 아키텍처를 보여주기 좋은 주제라고 봤다.

## 차별점과 확장

- OSSInsight와 달리 개인 계정 분석 + AI 커리어 리포트를 얹는 점이 차별이다.
- Hugging Face 모델 트렌딩은 GitHub 본체가 나온 뒤 W4 확장으로 두기로 했다.
