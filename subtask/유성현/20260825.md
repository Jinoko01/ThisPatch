## Hadoop MapReduce 학습

### Matrix Multiplication 학습
- 행렬 곱셈의 성립 조건과 행·열 간 연산 구조 학습
- 결과 행렬의 좌표를 기준으로 연산에 필요한 데이터를 구성하는 방식 이해
- MapReduce에서 연산에 필요한 데이터 관계를 Key로 표현하는 설계 방식 학습

### Matrix Multiplication 구현
- Mapper에서 결과 행렬의 좌표를 Key로 생성
- Shuffle & Sort를 통해 동일 결과 좌표에 필요한 데이터를 하나의 Reducer로 전달
- Reducer에서 같은 인덱스의 원소를 곱한 뒤 합산하여 결과 행렬 계산
- 행렬 곱셈 연산을 Key-Value 기반의 분산 처리 구조로 변환하여 구현
