## Hadoop MapReduce 학습

### MapReduce Join 학습
- 대용량 데이터의 Join 연산을 파티션 단위로 분산 처리하는 구조 학습
- 비교 대상 데이터를 동일 Reducer로 전달하기 위한 Key 설계 방식 이해
- 파티션 조합을 이용해 비교 범위를 분산시키는 방식 학습

### All Pair Partition Join 구현
- 튜플을 무작위 파티션에 배정하고 파티션 쌍을 Key로 생성
- Shuffle & Sort를 통해 비교가 필요한 데이터를 동일 Reducer로 전달
- Reducer에서 파티션 조합에 따라 Record Pair 생성
- 전체 데이터를 직접 비교하지 않고 파티션 단위로 Join을 수행하는 방식 이해

### Self Join 구현
- 하나의 데이터 집합 내부에서 모든 Record Pair를 생성하는 Self Join 구현
- 동일 파티션 및 서로 다른 파티션 간 Record Pair 생성 방식 학습
- 중복되지 않는 Record Pair를 생성하기 위한 조건 처리 방식 확인

### Reducer 출력 구조 확인
- Reducer 개수에 따라 결과가 여러 `part-r-*` 파일로 분리되는 과정 확인
- 여러 Reducer가 독립적으로 처리한 결과를 각각 출력 파일로 생성하는 구조 이해
