# TIL - 2026-08-20 (목)

## 오늘 한 것

`MatrixAdd`와 `MatrixMulti`를 구현하며 행렬 연산에 필요한 key 설계와 중간 데이터 생성을 학습했다.

### 1. `MatrixAdd`

- 입력을 `행렬 이름, 행, 열, 값` 형태로 파싱했다.
- 행과 열 좌표를 key로 사용해 같은 위치의 원소를 묶었다.
- Reducer에서 같은 좌표의 값을 합산해 행렬 덧셈을 수행했다.
- 기존 HDFS output 경로를 확인하고 필요한 경우 삭제하는 처리를 추가했다.

### 2. `MatrixMulti`

- 행렬 크기 `n`, `l`, `m`을 `Configuration`으로 전달했다.
- A 행렬 원소는 결과 행렬의 열 방향으로, B 행렬 원소는 행 방향으로 복제했다.
- 결과 행렬의 같은 좌표를 key로 사용해 곱셈에 필요한 부분값을 모았다.
- 이번 실습에서는 최종 합산 전 단계인 중간 데이터 생성 구조를 확인했다.

## 배운 것

- 행렬 연산에서는 결과 좌표를 key로 설계하면 같은 위치의 데이터들을 Reducer에서 함께 처리할 수 있다.
- Job 실행에 필요한 행렬 크기와 같은 값은 `Configuration`으로 전달할 수 있다.
- 하나의 MapReduce Job에서 모든 계산을 끝내지 않고, 중간 결과를 다음 단계에서 처리하는 구조를 사용할 수 있다.

## 느낀 점

행렬 곱셈은 단순히 두 값을 곱하는 것이 아니라 같은 결과 좌표로 모아야 할 데이터를 미리 복제하고 분배해야 했다. 데이터의 이동과 그룹화 방식을 먼저 설계하는 것이 중요하다는 것을 느꼈다.
