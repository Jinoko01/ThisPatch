# TIL - 2026-08-19 (수)

## 오늘 한 것

`Wordcountsort`와 `InvertedIndex`를 구현하며 Partitioner와 입력 파일 위치 정보 활용 방법을 학습했다.

### 1. `Wordcountsort`

- `Wordcount`에 사용자 정의 `MyPartitioner`를 추가했다.
- 단어의 첫 글자를 기준으로 데이터를 두 Reducer에 분배했다.
- 같은 규칙으로 분배된 데이터가 각 Reducer에서 처리되는 것을 확인했다.

### 2. `InvertedIndex`

- Mapper 입력 key인 파일 offset과 `FileSplit`에서 입력 파일 이름을 가져왔다.
- 단어를 key로, `파일 이름: 위치`를 value로 출력했다.
- Reducer에서 같은 단어의 파일명과 위치 정보를 하나로 모아 역색인을 만들었다.

## 배운 것

- Partitioner는 Mapper 결과를 어떤 Reducer로 보낼지 결정한다.
- 기본 HashPartitioner 대신 업무 규칙에 맞는 데이터 분배 방식을 직접 구현할 수 있다.
- 입력 key의 offset과 파일 이름을 이용하면 단어가 어느 파일의 어느 위치에 등장했는지 기록할 수 있다.

## 느낀 점

Reducer에서 집계하는 것뿐 아니라 그 전에 데이터를 적절한 Reducer로 분배하는 과정도 MapReduce의 중요한 구성 요소라는 것을 알게 되었다. 또한 같은 단어라도 파일별 위치 정보까지 보존하면 검색에 활용할 수 있는 결과가 된다는 점이 흥미로웠다.
