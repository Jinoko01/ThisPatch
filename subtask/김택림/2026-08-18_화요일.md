# TIL - 2026-08-18 (화)

## 오늘 한 것

Hadoop을 설치하고 MapReduce의 기본 예제인 `Wordcount`와 `Wordcount1char`를 실습했다.

### 1. Hadoop 설치 및 환경 구성

- Hadoop 3.2.2, Java 8, Ant, SSH를 설치했다.
- localhost 단일 노드 환경에서 HDFS를 구성했다.
- HDFS 기본 경로와 Linux 로컬 경로가 서로 다른 저장 공간이라는 점을 확인했다.

### 2. `Wordcount`

- Mapper에서 한 줄을 단어 단위로 분리해 `(단어, 1)`을 출력했다.
- Shuffle/Sort에서 같은 단어끼리 그룹화되는 과정을 확인했다.
- Reducer에서 같은 단어의 값을 합산해 단어별 빈도를 계산했다.

### 3. `Wordcount1char`

- `Wordcount`의 Mapper 로직을 변형했다.
- 단어 전체가 아닌 첫 글자를 key로 사용했다.
- 첫 글자별 등장 횟수를 집계했다.

## 배운 것

- Hadoop MapReduce는 `Mapper → Shuffle/Sort → Reducer` 흐름으로 동작한다.
- 기본 `TextInputFormat`에서 Mapper의 key는 줄 번호가 아닌 파일 내 Byte Offset이다.
- Hadoop에서는 분산 전송을 위해 Java 기본 타입 대신 `Text`, `IntWritable` 같은 `Writable` 타입을 사용한다.

## 느낀 점

간단한 단어 개수 세기라도 key를 어떻게 설계하느냐에 따라 단어별 집계나 첫 글자별 집계처럼 결과가 달라지는 것을 확인했다. MapReduce에서 key 설계가 중요하다는 점을 처음으로 체감했다.
