## 아이디어 회의
- 주말 동안 각자 준비한 빅데이터 분산 처리 프로젝트 아이디어 논의
- 프로젝트 주제 후보 비교 및 방향 검토

## Hadoop MapReduce 학습

### HDFS 및 MapReduce 구조
- Hadoop의 HDFS와 MapReduce 구조 학습
- `Map → Shuffle & Sort → Reduce` 처리 흐름 이해
- 동일한 Key를 가진 데이터가 Shuffle & Sort를 통해 같은 Reducer로 전달되는 구조 확인

### Partitioner 학습
- Key를 기준으로 데이터를 원하는 Reducer에 분배하는 Partitioner의 역할 학습
- Reducer별 데이터 분배 방식을 제어하는 방법 이해

### Inverted Index 구현
- MapReduce를 활용한 Inverted Index 구현
- 원소를 Key, 해당 원소가 포함된 Record를 Value로 구성하는 방식 학습
- 검색 및 데이터 관계 분석에 활용할 수 있는 Key-Value 구조 이해

### Matrix Addition 구현
- MapReduce를 활용한 행렬 덧셈 구현
- 행렬 좌표를 Key로 활용해 관련 데이터를 동일 Reducer에서 처리하는 방식 학습
- 일반적인 행렬 연산을 Key-Value 기반의 분산 처리 문제로 변환하는 방법 학습
