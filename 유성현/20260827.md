## Hadoop MapReduce 학습

### CommonItemCount 학습 및 구현
- Inverted Index를 활용하여 레코드 간 공통 원소 개수를 계산하는 방식 학습
- Mapper에서 각 원소를 Key, 해당 원소를 포함한 Record ID를 Value로 출력
- Reducer에서 같은 원소를 포함하는 Record ID를 모아 모든 Record ID Pair 생성
- `<Record Pair, 1>` 형태의 중간 결과를 생성한 뒤 두 번째 MapReduce Job에서 합산
- 복잡한 처리를 여러 MapReduce Job으로 나누어 수행하는 방식 학습

### Top-K Search 학습 및 구현
- 2차원 좌표 데이터에서 Query Point와 가까운 Top-K Point를 찾는 방식 학습
- Record ID를 기준으로 데이터를 여러 파티션으로 분배
- 각 파티션의 Reducer에서 Query Point와의 Euclidean Distance 계산
- `PriorityQueue`를 활용해 각 파티션에서 가장 가까운 K개의 후보만 유지
- Local Top-K 결과를 하나의 Key로 모아 최종 Global Top-K 계산
- `Local Top-K → Global Top-K` 구조를 이용해 중간 데이터 양을 줄이는 분산 집계 방식 이해

### HDFS 및 Hadoop 실행 과정
- `hdfs dfs -mkdir`, `hdfs dfs -put`, `hdfs dfs -cat`을 이용한 HDFS 데이터 관리 방법 학습
- 일반 Linux 명령어와 HDFS 명령어의 차이 확인
- `Driver.java`에 Hadoop 프로그램을 등록하고 `ant`를 통해 JAR를 다시 빌드해야 변경사항이 적용되는 과정 확인

### Hadoop Job 디버깅
- `Map input records`, `Map output records`, `Reduce output records` 등 Job Counter를 통한 데이터 처리 흐름 확인
- Mapper에서 `context.write()`를 실행하지 않을 경우 `Map output records=0`이 되는 문제 확인
- Job Counter와 실행 결과를 이용해 MapReduce 데이터 흐름을 점검하는 방법 학습
