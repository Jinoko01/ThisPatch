### 확정된 주제

Steam 리뷰 대규모 분산 분석 기반 게임 운영 진단 플랫폼

### 핵심 차별점

리뷰를 **첫 작성 / 수정된 리뷰** 채널로 분리하면, 단일 집계에서는 확인되지 않는 신호가 드러난다.

| 채널 | 패치일 긍정률 | 플레이 이력 중앙값 |
|---|---|---|
| 첫 작성 | 46.7% | 118.8시간 |
| **수정된 리뷰** | **13.9%** | **194.7시간** |

표본 505건, 평시 1,945건에서 재현, `playtime_at_review`로 교차검증 완료.

> - "대응 속도"를 측정하려다 평소 패치 빈도를 측정
> - "이탈률"을 측정하려다 경과 시간 차이를 측정

>
> 모두 다른 조건과 비교하지 않으면 그대로 채택했을 결과다.
